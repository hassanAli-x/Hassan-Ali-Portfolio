# Hassan Ali — Portfolio

A modern, responsive portfolio website built with **React**, **Vite**, and **Tailwind CSS** to showcase projects, skills, and experience.

## Features

* Responsive, mobile-first design
* Light and dark mode
* Project showcase
* Skills and technologies section
* Resume page
* Contact page
* Clean, modern UI

## Tech Stack

* React
* Vite
* Tailwind CSS
* React Router

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Customization

You can easily personalize the portfolio by updating the files inside the `src/data/` directory with your own:

* Projects
* Skills
* Experience
* Personal information
* Social links
